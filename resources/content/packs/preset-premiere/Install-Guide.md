# Premiere Pro - Install LUTs & Export Presets

**Apply a LUT (Lumetri Color)**
1. Effects panel -> Lumetri Color
2. Creative tab -> Look -> Browse
3. Pick any .cube from this pack

**Recommended export (TikTok/Shorts/Reels)**
- Format: H.264
- Resolution: 1080x1920
- Frame rate: 60 FPS
- Bitrate: 8 Mbps VBR 2-pass
- Profile: High
- Audio: AAC 128 kbps
